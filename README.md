# LlamaParse_to_parse_PDF

In this repo - I would like to show how to use LlamaParse to parse a PDF document.

The Input document to be converted is a PDF file ( e.g: Electoral Roll PDF listing all the voters in a certain constituency).

Each page is in this Voters List is an image of voters with their voter id, name, age, gender address etc, and contents cannot be extracted directly. A Sample of the page is shown below.

These are about 20 to 30 pages of PNG or JPG images, which is now showing up as a PDF document. The challenge is that the 

The text in this cannot be extracted directly, **Each page has to be converted from the IMG ( PNG or JPG ) and the text has to be 
extracted using OCR, and this is being done by LlamaParse in the backend. **

LlamaParse is an Open Source tool that allows users to extract contents of each page and creates a MarkDown md file as an output.

The code as generated by the LlamaParse, Here I have selected Javascript, and one could choose Python.

```
import LlamaCloud from "@llamaindex/llama-cloud";
import fs from "fs";

const client = new LlamaCloud({
  apiKey: "llx-...",
});

async function main() {
  // Upload
  const fileObj = await client.files.create({
    file: fs.createReadStream("./document.pdf"),
    purpose: "parse",
  });

  // Submit + poll + get (parsing.parse wraps create / waitForCompletion / get)
  // Throws on FAILED or CANCELLED. Tune pollingInterval / timeout in the options.
  const result = await client.parsing.parse({
    file_id: fileObj.id,
    tier: "agentic",
    version: "latest",
    // expand: which fields to materialize (markdown_full, text_full, items, *_content_metadata, ...)
    expand: ["markdown_full", "text_full"],
  });

  // Persist markdown and text to disk
  fs.writeFileSync("output.md", result.markdown_full ?? "");
  fs.writeFileSync("output.txt", result.text_full ?? "");
  console.log(`Wrote ${(result.markdown_full ?? "").length} chars markdown, ${(result.text_full ?? "").length} chars text`);
}

main().catch(console.error);

```
